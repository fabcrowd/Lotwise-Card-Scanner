Sweep is on this PC

Three steps in Chrome finish the setup.

Version {{VERSION}}

  1. Open the Extensions page.

    Open a new tab, paste this address into the address bar and press Enter. A web page cannot link to it, so it is shown as text.

    Or click the three-dot menu, then Extensions, then Manage Extensions.

  2. Switch on Developer mode.

    The switch is in the top right corner of the Extensions page.

  3. Click Load unpacked and paste the folder.

    Click Copy next to the folder below. In the folder window, click the address bar at the top (or press Ctrl+L), paste with Ctrl+V, press Enter, and click Select Folder.

After that

Pin Sweep from the puzzle-piece menu in Chrome's toolbar. Click the Sweep icon and choose Download models (about 147 MB, one time).

Why these steps?

Chrome installs an extension automatically only from the Chrome Web Store. Sweep is not in the store yet.

If Windows warned you

Sweep Setup is not code-signed, so Windows may have shown a "Windows protected your PC" (SmartScreen) notice when you ran it. Choosing More info and then Run anyway is expected. Download Sweep Setup only from the project's own release page.

If Chrome shows a notice at start-up

Because Sweep is loaded unpacked, Chrome shows a "Disable developer mode extensions" notice each time it starts. That is expected. Close the notice and Sweep stays on.

Updating

Run the newer Sweep Setup, then click the reload arrow on Sweep's card on the Extensions page.

Removing

Open Windows Settings, then Apps, then Installed apps, and remove Sweep card scanner. Then click Remove on Sweep's card on the Extensions page.
